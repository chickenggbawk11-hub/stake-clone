# Stake.com Clone - Next.js Application

A modern, fully-featured cryptocurrency casino and sports betting platform built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **🎮 Casino Games** - Browse and filter through thousands of casino games
- **⚽ Sports Betting** - Live sports betting with competitive odds
- **💎 Cryptocurrency Support** - Simulated crypto wallet and transactions
- **🎨 Modern UI** - Beautiful, responsive design with gradient effects
- **📱 Mobile Responsive** - Fully optimized for all devices
- **⚡ Fast Performance** - Optimized with Next.js
- **🌙 Dark Theme** - Eye-friendly dark mode design

## 📋 Prerequisites

- Node.js 16+ or higher
- npm or yarn package manager

## 🔧 Installation

1. Clone the repository
   ```bash
   git clone https://github.com/chickenggbawk11-hub/stake-clone.git
   cd stake-clone
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Run the development server
   ```bash
   npm run dev
   ```

4. Open your browser and go to `http://localhost:3000`

## 📦 Build for Production

```bash
npm run build
npm run start
```
